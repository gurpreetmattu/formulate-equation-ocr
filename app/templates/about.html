About This Project

Automated Printed Equation Recognition & LaTeX/MathML Conversion from Images

This application converts images of printed mathematical equations into LaTeX and MathML using a custom deep learning pipeline, so they can be reused in LaTeX papers, Word documents, and web pages.

Key Features

  • End-to-end OCR: image → LaTeX & MathML
  • Dual decoding: Greedy and Beam Search outputs shown side by side
  • Visual comparison against the preprocessed input image
  • Example gallery with ground-truth comparisons

Technical Highlights

  • Model architecture: LWDSC-SA (lightweight depthwise-separable conv + spatial attention) encoder → BiLSTM sequence model → Luong-attention LSTM decoder
  • Dataset: im2latex-100k
  • Preprocessing: adaptive cropping, contrast/sharpness enhancement, Otsu binarization, fixed-size resize
  • Conversion pipeline: Image → LaTeX (deep learning) → MathML (latex2mathml)

Limitations

  • Best on high-quality scans of printed (not handwritten) equations
  • May require post-editing for deeply nested or unusual formulas

Acknowledgments

Inspired by Mathpix, im2latex, and the PyTorch/Flask communities.
