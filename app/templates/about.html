About

Automated printed equation recognition

A deep learning pipeline that converts images of printed math equations into LaTeX and MathML, so they can be reused in papers, documents, and web pages.

How it works

Image
Preprocess
LWDSC-SA Encoder
BiLSTM + Attention Decoder
LaTeX + MathML

Beam search decoding is shown as the primary result since it's usually more accurate; greedy decoding runs alongside it and is available as a faster, secondary comparison.

Key features

  • End-to-end OCR — image in, editable LaTeX and MathML out.
  • Dual decoding — greedy and beam search results shown together for comparison.
  • Visual verification — the preprocessed input and rendered LaTeX are shown alongside the raw output.
  • Example gallery — sample equations compared against ground truth.

Technology

Python PyTorch OpenCV Flask latex2mathml Docker Google Cloud Run

Limitations

  • Best on high-quality scans of printed (not handwritten) equations.
  • May require post-editing for deeply nested or unusual formulas.

Dataset: im2latex-100k. Inspired by Mathpix, im2latex, and the PyTorch/Flask communities.
